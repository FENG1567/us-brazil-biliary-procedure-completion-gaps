# R Package Requirements

The R scripts use the following packages in addition to base R:

- `arrow`
- `data.table`
- `ggplot2`
- `lme4`
- `patchwork`
- `ragg`
- `scales`
- `survey`
- `svglite`

Base or recommended R packages used by the scripts include `grid`, `parallel`, and `splines`.

Package versions should be recorded with `sessionInfo()` when the restricted analyses are rerun. Exact numerical reproduction may depend on the licensed data release, R version, package versions, and platform-specific numerical libraries.
