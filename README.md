# Multilevel Gaps in Recorded Biliary Procedure Completion

This repository provides the public reproducibility package for a cross-system study of recorded definitive biliary procedure completion in the United States and Brazil. It contains analysis code, concept-level codebooks, statistical analysis plans, non-identifying aggregate source data, figures, and publication files.

## Public release boundary

The repository contains no patient-level records from the US National Readmissions Database (NRD), SIH-SUS, CNES, IBGE, or any other source. NRD microdata cannot be redistributed under the Healthcare Cost and Utilization Project (HCUP) data-use agreement. Fine-grained NRD hospital-year outputs containing exact small cells are also excluded from the public release and must be regenerated by approved users in their secure environment.

The included CSV files contain aggregate estimates, figure source data, concept definitions, or summary results. They are not substitutes for the restricted source data and do not make the complete patient-level analysis executable without independent data access.

## Repository map

- `data/codebooks/`: concept-level NRD and SIH-SUS codebooks; these are not patient records.
- `data/aggregate/`: non-identifying snapshots of the main US and pancreatitis results.
- `data/source_data/`: aggregate source data underlying the displayed figures and selected tables.
- `scripts/final/`: final analysis scripts for the US and Brazil modules; several scripts require independently obtained source data.
- `scripts/legacy/`: earlier-stage scripts retained to document analysis development.
- `protocols/`: statistical analysis plans, the figure contract, and the cohort-harmonization note.
- `figures/`: final manuscript figures in PDF format.
- `publication/`: the integrated manuscript, supplementary file, and main tables.
- `requirements.txt` and `R_PACKAGES.md`: Python and R dependency lists.

## Reproduction route

1. Obtain the permitted 2018–2022 NRD files through HCUP and the required Brazilian inputs through their source organizations.
2. Review the frozen definitions and statistical plans in `protocols/` and the codebooks in `data/codebooks/`.
3. Run the scripts in `scripts/final/` in the order documented by the analysis plans.
4. Compare regenerated aggregate outputs with `data/aggregate/` and `data/source_data/`.

Exact reproduction depends on the licensed source-data releases and software environment used by the analyst. The public repository does not bypass any source licence, institutional agreement, or data-use agreement.

## Interpretation guardrails

The US analysis is observational and uses a Day-3 administrative landmark. The 90-day endpoint is the first observed biliary-related inpatient return and may include planned staged treatment. The choledocholithiasis exposure is a duct-directed procedure proxy and does not verify stone clearance. The Brazil module is an independent admission-level descriptive replication, not a patient-level external validation of the US estimand.
